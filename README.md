Проект содержит второе задание части автоматизации для яндекс практикум
Задание оринтированно на тестирование API учебного веб-приложения
В проекте содержатся следующие папки и файлы:
    1) allure_results - содержит файлы отчета о тестировании, просмотреть отчет можно командой: allure serve allure_results
    2) functions содержит файлы:
        a) base - содержит функции генерации случайных значений
        b) order - содержит функции касающиеся взаимодействий с данными заказов
        c) user - содержит функции касающиеся взаимодействий с данными пользователя
    3) tests содержит файлы:
        a) test_create_order - содержит тесты для апи создающего заказы
        b) test_create_user - содержит тесты для апи регистрирующего пользователей
        c) test_login - содержит тесты для апи входа в профиль пользователя
    4) conftest - содежит фикстуры для тестов
    5) constants - содержит ссылки используемые тестами и их функциями
    6) data - содержит тестовые данные
    7) requirements - содержит весь список библиотек установленных у разработчика тестов, установить библиотеки можно командой: pip install -r requirements.txt
